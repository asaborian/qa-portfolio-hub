## 📝 Recent Learning Logs

- **2026-09-02 02:07**: Scalaはオブジェクト指向と関数型プログラミングを統合したマルチパラダイムの静的型付け言語であり、Java仮想マシン上で動作する。クラスの多重継承には非対応だが、トレイトを用いて複数の振る舞いを組み込める特徴を持つ。
- **2026-09-01 22:43**: 再入可能（リエントラント）プログラムとは、複数のタスクから同時に並行して呼び出されても干渉せず、それぞれのタスクに正しい結果を返すプログラム構造のことである。手続き部分（命令）とデータ部（変数）を分離し、データ部をタスク別に保持することで実現する。混同しやすい他の用語として、①自分自身を呼び出すのは「再帰（リカーシブ）」、②主記憶のどこに配置しても実行できるのは「再配置可能（リロケータブル）」、③プログラムを分割して必要な部分のみ主記憶に読み込むのは「オーバーレイ」である。
- **2026-09-01 22:40**: 二分木を配列で表現する場合、要素は「上の階層から順に、左から右へ」詰め込まれる。そのため、配列の先頭から普通にインデックス順（A[1], A[2], A[3]...）に調べる動きは、自動的に「同じ階層（横方向＝幅）を全滅させてから下の階層へ進む」探索になる。つまり、「配列の通常の順番＝幅優先探索」と同義である。
- **2026-09-01 22:28**: 主成分分析（PCA）の本質は「次元削減（変数の数を減らすこと）」である。複数の変数を統合して新たな合成変数（主成分）を作成し、情報の損失を最小限に抑えつつデータを圧縮・理解しやすくする。他の統計手法との違いとして、①「潜在的な共通要因を探る」のは因子分析、②「他の変数を予測・関連性を確認する」のは回帰分析、③「類似するデータをグループ化する」のはクラスタ分析である。「主成分分析＝変数の数を減らす（次元削減）」というキーワードで識別する。
- **2026-09-01 22:24**: 浮動小数点数の「情報落ち」問題は、2進数の筆算を行わず次の2段階フィルターで判断する。①「絶対値の小さい数（負の指数）同士を先に計算しているか」で大＋小を計算している選択肢を除外する。②カッコ内の演算結果により大きい数（2^5）との指数差が仮数部の保持可能桁数（7ビット）以内に収まるかを確認する。足し算で桁繰り上がりが生じ、指数差が8から7へ縮まる選択肢が正解となる。本質は「小さい順の計算」と「指数差の縮小」の確認のみである。

## 💬 Interview FAQ

### Q: 就職したらどのように貢献できるか？
A: セキュリティスペシャリスト(SC)の知識を活かし、JSTQBの標準的なテスト技法に基づいて、Playwrightを活用したテスト自動化を構築できます。

### Q: 勤務形態に関して合意が必要な条件はあるか？
A: 育児（幼稚園の送迎等）と両立できるよう、内定承諾時に以下の勤務条件が労働条件通知書等で確認・合意できることを前提としております。

1. **原則リモートワーク**
   * オンボーディングに伴う出社期間は入社後最大3ヶ月間とし、それ以降は原則リモートワークへ移行すること。
   * リモート移行後も月1回程度の出社や緊急時の対応は可能ですが、高頻度な定例出社（週1回・隔週等）がないこと。
2. **勤務時間の柔軟性**
   * フレックス制度であり、13:30以降はコアタイム等の拘束がないこと（※早朝や夜間を活用して総労働時間を確保します）。

書面にて合意することで、入社後のミスマッチを防止したいと考えております。

### Q: なぜ37歳実務未経験でITエンジニアを目指すに至ったのか？
A: 現職の業務効率化のためにExcelマクロを使うようになり、プログラミングが楽しいと感じて仕事にしたいと考えたのが始まりです。当初は、「いつか個人開発や案件で生計を立てられたらいいな」という程度の考えで、転職時期については深く考えずに、趣味レベルで独学を続けていました。しかし、子どもが生まれたことをきっかけに、育休終了後の生活について夫婦で話し合った結果、「育児（幼稚園の送迎等）と両立できる仕事への転職」が最適であるという結論に至りました。そこで、もともとなりたいと思っていたITエンジニアへの挑戦を決め、自分に合いそうな職種として、セキュリティに強いQAエンジニアというポジションを目指すことにしました。
