## 📝 Recent Learning Logs

- **2026-09-29 22:32**: R言語とは、統計解析、データ分析、およびデータの可視化（グラフ作成）に特化したオープンソースのプログラミング言語・実行環境である。変数の型定義を事前に行う必要がない動的型付け言語であり、データ構造を柔軟に扱える特性を持つ。豊富な統計ライブラリ（パッケージ）や描画機能を標準で備えており、ビッグデータ解析、機械学習、学術研究、品質管理などの分野で広く利用されている。
- **2026-09-29 22:28**: ISMAP（Information System Security Management and Assessment Program：政府情報システムのためのセキュリティ評価制度）とは、政府機関がクラウドサービスを導入する際、安全性評価の統一的な基準に基づいてセキュリティ対策レベルを事前に評価・提示する制度である。内閣サイバーセキュリティセンター（NISC）、デジタル庁、総務省、経済産業省が運用し、あらかじめ安全性が確認されたクラウドサービスを「登録サービスリスト」として公開することで、各政府機関における安全なクラウド導入の推進と調達の効率化を図る。
- **2026-09-29 22:22**: OC曲線（検査特性曲線）とは、抜取検査においてロットの不良率とそのロットが合格する確率との関係を示したグラフである。横軸にロットの不良率、縦軸に合格確率をとり、不良率が高くなるほど合格確率は低下する曲線を描く。OC曲線を用いることで、生産者危険（合格すべき良品ロットが誤って不合格となる確率）や消費者危険（不合格にすべき不良ロットが誤って合格となる確率）を視覚的に評価・分析することができる。
- **2026-09-29 00:25**: エンタープライズアーキテクチャ（EA）とは、組織全体の業務およびシステムを「ビジネス」「データ」「アプリケーション」「テクノロジ」の4つの層に分類・整理し、全体最適化を図るための設計思想・枠組みである。選択肢において「企業の業務プロセスにおけるデータの流れを視覚的に表したもの」といった記述が出題される場合があるが、これはDFD（Data Flow Diagram：データフロー図）の説明であり誤りとなる。EAは特定の図式を指すのではなく、組織全体の構造体系そのものを指す点に留意が必要である。
- **2026-09-29 00:03**: コンカレントエンジニアリングとは、製品開発において設計、生産技術、製造、品質管理などの各工程を同時並行的に進める開発手法である。各部門が初期段階から情報を共有・連携することで、手戻りの防止、開発期間の短縮、およびコスト削減を図る。対義語はシーケンシャルエンジニアリング（ウォーターフォール型の順次開発）であり、設計から製造までの各工程を前工程の完了後に順番に遂行する従来型の開発アプローチを指す。

## 💬 Interview FAQ

### Q: 就職したらどのように貢献できるか？
A: セキュリティスペシャリスト(SC)の知識を活かし、JSTQBの標準的なテスト技法に基づいて、Playwrightを活用したテスト自動化を構築できます。

### Q: どのような企業形態・契約形態を希望しているか？
A: 育児（幼稚園の送迎等）と両立可能な環境であることを前提に、広く機会を探しております。SaaS・SIer・QA専門企業といった事業形態や、正社員・業務委託等の契約形態にはこだわりません。第一希望としては、育児のゆとりや自己学習の時間を設けやすい**短時間（週20時間程度や時短）でのスタート**ですが、フルフレックス制度等で時間の調整が可能であれば、**最初からフルタイム（1日8時間稼働）での参画**も喜んでお受けいたします。具体的には、内定・契約時に以下の点が書面で確認・合意できることを前提としております。

1. **原則リモートワーク**
   * オンボーディングに伴う出社期間は入社後最大3ヶ月間とし、それ以降は原則リモートワークへ移行すること。
   * リモート移行後も月1回程度の出社や緊急時の対応は可能ですが、高頻度な定例出社（週1回・隔週等）がないこと。
2. **勤務時間の柔軟性**
   * 13:30以降はコアタイム等の拘束がないこと。早朝・午前・夜間等、育児中ではない時間帯で総労働時間を確保できること。

書面にて合意することで、入社後のミスマッチを防止したいと考えております。

### Q: なぜ37歳実務未経験でITエンジニアを目指すに至ったのか？
A: 現職の業務効率化のためにExcelマクロを使うようになり、プログラミングが楽しいと感じて仕事にしたいと考えたのが始まりです。当初は、「いつか個人開発や案件で生計を立てられたらいいな」という程度の考えで、転職時期については深く考えずに、趣味レベルで独学を続けていました。しかし、子どもが生まれたことをきっかけに、育休終了後の生活について夫婦で話し合った結果、「育児（幼稚園の送迎等）と両立できる仕事への転職」が最適であるという結論に至りました。そこで、もともとなりたいと思っていたITエンジニアへの挑戦を決め、自分に合いそうな職種として、セキュリティに強いQAエンジニアというポジションを目指すことにしました。
