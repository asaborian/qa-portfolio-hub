## 📝 Recent Learning Logs

- **2026-10-10 21:34**: 乗数は掛け算における「掛ける側の数」であり、累乗において同じ数を掛け合わせる回数を示す「指数」とは異なる概念である。
- **2026-10-10 00:05**: プロセス間におけるデッドロック発生可能性の判定においては、各プロセスが最初に要求する資源（着手資源）が最重要指標となる。全プロセスが同一の資源を最初に占有する試みを行う構造であれば、先頭の資源獲得時点で排他制御（順番待ち）が機能するため、複数プロセスが互いの必要資源を抱え込んだまま停止するデッドロックは発生しない。一方で、各プロセスが異なる資源から占有を開始する場合は、相互に異なる資源を同時に確保してすれ違い（循環待機）が生じ、デッドロックが引き起こされる。
- **2026-10-08 22:52**: メモリインターリーブとは、物理メモリ（RAM）を複数の独立したブロック（バンク）に分割し、連続するアドレスへのアクセスを複数のバンクへ交互（インターリーブ）に分散させることで、メモリのデータ転送速度を向上させる技術である。単一のメモリバンクに連続アクセスする場合、データの読み書き後に「バンクの活性化」や「プリチャージ」といった動作待ち時間（レイテンシ）が発生し、CPUが待機状態になる。メモリインターリーブを採用すると、一方のバンクがアクセスの準備（レイテンシ処理）を行っている間に、別のバンクへデータアクセスを実行できる。これにより、バンクの処理待ち時間が覆い隠され（レイテンシの隠蔽）、バス幅を効率的に活用して連続アクセス時の実効データ転送速度が向上する。現代のPCやサーバーで広く利用されている「デュアルチャンネル」や「クアッドチャンネル」は、このメモリインターリーブの仕組みを物理的なメモリチャネルレベルに拡張・応用したものである。
- **2026-10-07 22:35**: 2.4GHz帯の無線LAN（IEEE802.11b/g等）では、1チャネルあたりの周波数帯域が約22MHzであるのに対し、チャネル間隔が5MHz刻みで設定されているため、近接するチャネル同士では電波の帯域が一部重複して電波干渉が発生する。電波干渉を回避するためには、隣接するアクセスポイント間で「1・6・11」のようにチャネル番号を5つ以上離して割り当てる設計が必要である。なお、SSIDを分けても物理的な周波数の重複による干渉は防げない。一方、5GHz帯の無線LANでは各チャネルが完全に独立しているため、隣接チャネルによる干渉は発生しない特性を持つ。
- **2026-10-06 22:56**: デルファイ法とは、複数の専門家に対するアンケート調査を匿名で繰り返し行い、回答結果のフィードバックを重ねることで、意見の集約と合意形成を図る予測手法のことである。

## 💬 Interview FAQ

### Q: 就職したらどのように貢献できるか？
A: セキュリティスペシャリスト(SC)の知識を活かし、JSTQBの標準的なテスト技法に基づいて、Playwrightを活用したテスト自動化を構築できます。

### Q: なぜ37歳実務未経験でITエンジニアを目指すに至ったのか？
A: 現職の業務効率化のためにExcelマクロを使うようになり、プログラミングが楽しいと感じて仕事にしたいと考えたのが始まりです。当初は、「いつか個人開発や案件で生計を立てられたらいいな」という程度の考えで、転職時期については深く考えずに、趣味レベルで独学を続けていました。しかし、子どもが生まれたことをきっかけに、育休終了後の生活について夫婦で話し合った結果、「育児（幼稚園の送迎等）と両立できる仕事への転職」が最適であるという結論に至りました。そこで、もともとなりたいと思っていたITエンジニアへの挑戦を決め、自分に合いそうな職種として、セキュリティに強いQAエンジニアというポジションを目指すことにしました。

### Q: 現職の経験(ソフトスキル)は役に立つか？
A: 同僚との情報共有、上司の意向に沿った報連相、顧客との意思疎通や論点整理等のソフトスキルにおいては、現職の経験がそのまま活かせると考えています。また、単に作業を効率化するだけでなく、「そもそも作業自体を行わなくても済むようにする」ための根本的な調整や交渉にも意識的に取り組んでいました。公務員の仕事は、法令の範囲内で抜け漏れなく現状に即した解決策を見つけるというロジカルシンキングそのものであり、エンジニアの仕事にも役立つと考えています。それから、業務で日常的に法令の条文や国からの通知といった「厳格で論理的な文書」を読み慣れていることも、法改正やセキュリティ基準などのルールを守るうえで役立つと考えています。
