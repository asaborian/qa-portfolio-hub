## 📝 Recent Learning Logs

- **2026-10-27 17:12**: VNF（Virtual Network Function）は、ルーターやファイアウォールなどの個別のネットワーク機器の機能を汎用サーバー上でソフトウェアとして動作させる技術である。一方、SDN（Software-Defined Networking）は、ネットワークの制御機能とデータ転送機能を分離し、中央のコントローラーからネットワーク全体の通信経路やトラフィックを一元的に制御・管理するアーキテクチャである。両者は補完関係にあり、VNFによって必要なネットワーク機能をソフトウェアとして構築し、SDNによってそれらの通信経路を中央集権的に制御することで柔軟なネットワーク運用が実現される。
- **2026-10-27 16:10**: 多版同時実行制御(MVCC：MultiVersion Concurrency Control)は、トランザクションからの読書き要求に対して、トランザクション開始時点における同じデータのスナップショット（版、version）を提供するというアプローチにより、トランザクションの同時実行制御を行う仕組み
- **2026-10-25 12:16**: YAGNI（You Aren't Going to Need It）は、ソフトウェア開発において現時点で必要とされていない機能は、将来の予測で事前に実装すべきではないとする設計原則である。未確定な機能の事前実装はコードの複雑化や保守コストの増加を招くため、真に必要なタイミングが来るまで実装を延期することで、シンプルな設計と開発効率を維持する。
- **2026-10-25 12:13**: ブルーグリーンデプロイメントは、同一構成の2つの本番環境（Blue環境とGreen環境）を用意し、ルーターのルーティング切り替えによってダウンタイムなしで新バージョンへ移行するデプロイ手法である。新バージョンを非稼働側の環境にあらかじめデプロイして検証した上で瞬時に切り替えるため、リリースリスクを大幅に軽減できる特徴を持つ。
- **2026-10-25 11:34**: FPGAは製造後に内部の論理回路を何度でも書き換えられるプログラマブルな集積回路であり、ASICは特定の用途専用に回路が固定されたカスタムLSIである。

## 💬 Interview FAQ

### Q: 就職したらどのように貢献できるか？
A: セキュリティスペシャリスト(SC)の知識を活かし、JSTQBの標準的なテスト技法に基づいて、Playwrightを活用したテスト自動化を構築できます。

### Q: どのような働き方・契約形態を希望しているか？
A: SaaS、SIer、QA専門企業等の事業形態や、正社員・業務委託・スポット（短期）案件といった契約形態を問わず、幅広く機会を探しております。長期的な参画はもちろん、プロジェクト単位の関わり方も含めて柔軟に対応可能です。

**稼働・スケジュールに関するご相談**
* **オンボーディング（入社後最大3ヶ月間）:** フル出社可能です。
* **通常稼働（オンボーディング完了後）:** 原則リモートでの運用を希望いたします（月1回程度の定例出社であれば、事前に家族と調整のうえ対応いたします）。
* **2029年1月以降（妻の復職後）:** 毎日14:00〜18:00頃が自宅でのワンオペ育児時間となります。リモートワークおよびフレックス等でこの時間の調整（中抜けや時間振替）が可能であれば、**1日4時間の短時間から8時間フルタイムまで幅広く対応可能**です。
* **緊急対応:** ワンオペ育児中も連絡は繋がる状態です。緊急の際は、状況に応じて柔軟に対応いたします。

※上記の働き方が可能な勤務条件（出社頻度月一回、コアタイムなし等）について、内定・契約時に書面等で確認・合意させていただけますと幸いです。

### Q: なぜ37歳実務未経験でITエンジニアを目指すに至ったのか？
A: 現職の業務効率化のためにExcelマクロを使うようになり、プログラミングが楽しいと感じて仕事にしたいと考えたのが始まりです。当初は、「いつか個人開発や案件で生計を立てられたらいいな」という程度の考えで、転職時期については深く考えずに、趣味レベルで独学を続けていました。しかし、子どもが生まれたことをきっかけに、育休終了後の生活について夫婦で話し合った結果、「育児（幼稚園の送迎等）と両立できる仕事への転職」が最適であるという結論に至りました。そこで、もともとなりたいと思っていたITエンジニアへの挑戦を決め、自分に合いそうな職種として、セキュリティに強いQAエンジニアというポジションを目指すことにしました。
