# QA Portfolio Hub

> **💡 本リポジトリの目的**
> 
> 本リポジトリは、採用担当者様の参考資料として、私のQAエンジニア転職に向けた技術習得状況や、面接での想定質問に対する回答等を、事前にドキュメントとして公開しているものです。目的は以下の2点です。
> 
> 1. **意思と前提条件の正確な伝達**
>    面接当日の限られた時間やその場のやりとりだけでは、自身のキャリアに対する考え方や、想定している勤務条件を100%正確に伝えることは困難です。事前にテキストとして可視化しておくことで、認識の齟齬をなくすことを目的としています。
> 
> 2. **採用活動におけるミスマッチ防止**
>    私の現在のスキルセットや、育児との両立を目指した希望勤務条件（猶予期間を設けた上での原則リモートワーク等）をあらかじめ開示しております。企業様が求める人物像や要件と照らし合わせて選考の初期段階でご判断いただくことで不要な面接の発生を防ぎ、私よりも優秀な人材を求める企業様・採用担当者様に対して、選考の手間をおかけしないようにすることを目的としています。

## 💬 Interview FAQ

### Q: 就職したらどのように貢献できるか？
A: セキュリティスペシャリスト(SC)の知識を活かし、JSTQBの標準的なテスト技法に基づいて、Playwrightを活用したテスト自動化を構築できます。

### Q: なぜ37歳実務未経験でITエンジニアを目指すに至ったのか？
A: 現職の業務効率化のためにExcelマクロを使うようになり、プログラミングが楽しいと感じて仕事にしたいと考えたのが始まりです。当初は、「いつか個人開発や案件で生計を立てられたらいいな」という程度の考えで、転職時期については深く考えずに、趣味レベルで独学を続けていました。しかし、子どもが生まれたことをきっかけに、育休終了後の生活について夫婦で話し合った結果、「リモートワークができる企業への転職」が最適であるという結論に至りました。そこで、自分に合いそうな職種として、セキュリティに強いQAエンジニアというポジションを目指すことにしました。

### Q: 出社は可能か？ 
A: 採用後最初の3ヶ月間を上限として、職場のルールや基本業務をキャッチアップするための期間であれば、出社可能です。それ以降は、子どもの幼稚園の送り迎えのため、原則リモートワークの勤務形態へ移行する必要があります。なお、リモート移行後も、月1回程度の頻度や、事前に調整ができるスケジュールであれば、家族と調整のうえ出社可能です。
