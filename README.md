## 📝 Recent Learning Logs

- **2026-10-14 22:50**: 試験独特のおかしな表記について:クラス名のところに「販売実績 Subject」などと記載されていた場合、漢字部分だけでなく末尾の英単語（Subject等）を含めた表記全体を1つのクラス名として定義しているという意味である。クラス名を答える際は、最後まで含めた全体を記述する必要がある。
- **2026-10-13 23:18**: ER図において関連の線が存在する箇所には参照関係（外部キーの役割）が存在するが、当該属性が自テーブルの主キーを兼ねる場合は注記のルールにより実線が優先され破線は省略される。
- **2026-10-12 16:50**: サブネットは、内側からは直接ブロードキャストが届く範囲であり、外側からはプライベートIPアドレスの前24桁等のネットワークアドレスを単位として識別される。一方、ローカルネットワークは複数のサブネットの集合であり、外側からはローカルネットワークとインターネットの両方に接続する境界ルータが持つ1つのグローバルIPアドレスを単位として識別される空間である。なお、「セグメント」という言葉は特定の厳密な技術的定義があるわけではなく、文脈に応じてネットワークの単なる区切りを表す便利な言葉として使われる。
- **2026-10-12 16:21**: 応用情報技術者試験の構成変更に関する問題において、「経由しなくなる通信」や「不要となる機能」といった表現は、変更前の時点ですでに経由・使用していない通信は除外し、あくまで「従来（変更前）は経由していたが、変更に伴って経由しなくなる通信（ビフォーアフターの差分）」のみを対象とすることを指す。したがって、もとから経由していない通信は選択してはならない。
- **2026-10-12 15:55**: デフォルトゲートウェイは、異なるサブネット間におけるパケット転送（ルーティング）を行う中継機器である。同一サブネット内の通信はレイヤー2のMACアドレスを用いて直接行われるのに対し、宛先が異なるサブネットの場合は、端末は直接通信できないためパケットをデフォルトゲートウェイへ送信する。そのため、デフォルトゲートウェイとして機能する機器は、対象となるサブネットの内部に所属して内部端末からのパケットを受け取れると同時に、外部のネットワークとも接続されている必要がある。

## 💬 Interview FAQ

### Q: 就職したらどのように貢献できるか？
A: セキュリティスペシャリスト(SC)の知識を活かし、JSTQBの標準的なテスト技法に基づいて、Playwrightを活用したテスト自動化を構築できます。

### Q: なぜ37歳実務未経験でITエンジニアを目指すに至ったのか？
A: 現職の業務効率化のためにExcelマクロを使うようになり、プログラミングが楽しいと感じて仕事にしたいと考えたのが始まりです。当初は、「いつか個人開発や案件で生計を立てられたらいいな」という程度の考えで、転職時期については深く考えずに、趣味レベルで独学を続けていました。しかし、子どもが生まれたことをきっかけに、育休終了後の生活について夫婦で話し合った結果、「育児（幼稚園の送迎等）と両立できる仕事への転職」が最適であるという結論に至りました。そこで、もともとなりたいと思っていたITエンジニアへの挑戦を決め、自分に合いそうな職種として、セキュリティに強いQAエンジニアというポジションを目指すことにしました。

### Q: 現職の経験(ソフトスキル)は役に立つか？
A: 同僚との情報共有、上司の意向に沿った報連相、顧客との意思疎通や論点整理等のソフトスキルにおいては、現職の経験がそのまま活かせると考えています。また、単に作業を効率化するだけでなく、「そもそも作業自体を行わなくても済むようにする」ための根本的な調整や交渉にも意識的に取り組んでいました。公務員の仕事は、法令の範囲内で抜け漏れなく現状に即した解決策を見つけるというロジカルシンキングそのものであり、エンジニアの仕事にも役立つと考えています。それから、業務で日常的に法令の条文や国からの通知といった「厳格で論理的な文書」を読み慣れていることも、法改正やセキュリティ基準などのルールを守るうえで役立つと考えています。
