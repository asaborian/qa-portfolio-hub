## 📝 Recent Learning Logs

- **2026-09-24 00:13**: HTTPプロトコル自体はGETやPOSTのほかにPUTやDELETEなど多様なメソッドを定義しているが、HTMLの <form> タグは仕様上GETとPOSTしかサポートしていない。そのためNext.jsなどのフレームワークでは、通信レベル（TCP/IPのアプリケーション層）ではPOSTとしてデータを送信しつつ、フォーム内の隠しデータやミドルウェアによって内部でPUTやDELETEとして解釈・ルーティングする手法（Form Method Overriding等）が用いられている。また、Server Actions等の機能によりこれらの通信制御が抽象化・隠蔽されており、開発者はHTTP通信を直接意識することなく関数呼び出しのような記述でデータ操作を行えるようになっている。
- **2026-09-23 02:04**: テスト送信
- **2026-09-23 00:25**: ネットワーク通信やURLの設定において、宛先ポート番号を指定する場合はパスやクエリ文字列の前、すなわちホスト名（またはIPアドレス）の直後にコロン（:）で区切って記述する（例: http://example.com:8080/path/to/resource?key=value）。
- **2026-09-22 23:56**: フォールバック（Fallback）とは、システムやネットワークで障害が発生した際や通信条件の変化時に、機能を完全に停止させるのではなく制限された代替手段へ切り替えて運用を継続する仕組みのことである。移動体通信（モバイルネットワーク）の文脈においては、5Gから4G、または4Gから3Gへ接続規格を落として通信を維持することを指す。ハンドオーバー（Handover）とは、移動体通信において、移動中の端末が接続する基地局を通信を断絶させることなく自動的に別の基地局へ切り替える技術のことである。ローミング（Roaming）とは、契約している通信事業者のサービスエリア外において、提携している他の通信事業者の設備・ネットワークを経由して通信を利用できる仕組みのことである。
- **2026-09-22 00:33**: Playwright を '--headed' モードで実行した際、Linux 環境下において WebKit のみエラー（Failed to resize window 等）が発生することがある。これはアプリケーションやテストコード自体の不具合ではなく、OS のウィンドウマネージャやディスプレイ描画などローカルマシンの環境差に起因する挙動である。GitHub Actions 等の CI 環境ではすべてヘッドレスモード（'--headless'）で実行されるため、開発中にのみ発生する headed モード特有の動作不良は無視して差し支えない。

## 💬 Interview FAQ

### Q: 就職したらどのように貢献できるか？
A: セキュリティスペシャリスト(SC)の知識を活かし、JSTQBの標準的なテスト技法に基づいて、Playwrightを活用したテスト自動化を構築できます。

### Q: なぜ37歳実務未経験でITエンジニアを目指すに至ったのか？
A: 現職の業務効率化のためにExcelマクロを使うようになり、プログラミングが楽しいと感じて仕事にしたいと考えたのが始まりです。当初は、「いつか個人開発や案件で生計を立てられたらいいな」という程度の考えで、転職時期については深く考えずに、趣味レベルで独学を続けていました。しかし、子どもが生まれたことをきっかけに、育休終了後の生活について夫婦で話し合った結果、「育児（幼稚園の送迎等）と両立できる仕事への転職」が最適であるという結論に至りました。そこで、もともとなりたいと思っていたITエンジニアへの挑戦を決め、自分に合いそうな職種として、セキュリティに強いQAエンジニアというポジションを目指すことにしました。

### Q: 現職の経験(ソフトスキル)は役に立つか？
A: 同僚との情報共有、上司の意向に沿った報連相、顧客との意思疎通や論点整理等のソフトスキルにおいては、現職の経験がそのまま活かせると考えています。また、単に作業を効率化するだけでなく、「そもそも作業自体を行わなくても済むようにする」ための根本的な調整や交渉にも意識的に取り組んでいました。公務員の仕事は、法令の範囲内で抜け漏れなく現状に即した解決策を見つけるというロジカルシンキングそのものであり、エンジニアの仕事にも役立つと考えています。それから、業務で日常的に法令の条文や国からの通知といった「厳格で論理的な文書」を読み慣れていることも、法改正やセキュリティ基準などのルールを守るうえで役立つと考えています。
