## 📝 Recent Learning Logs

- **2026-08-06 17:21**: Next.js (App Router) における page.tsx と actions.ts の基本お作法 / ■1. page.tsxの原則：特別にブラウザ機能(useStateやonClick等)を使う理由がない限りは何も書かない(デフォルトのサーバーコンポーネントのままにしておくのが最もパフォーマンス・安全性が高いため)。 ■2. actions.tsの原則：DB操作等のサーバー処理関数をまとめる専用ファイルのため、先頭に'use server'を記述するのが標準ルール。
- **2026-08-06 17:18**: Next.jsの画面・処理分離と'use server'の仕組み/ ■1. 役割の分離：画面の表示をpage.tsxに書き、入力やクリック時に呼び出す処理はactions.tsからインポートして実行する。 ■2. サーバーコンポーネントとServer Actionsの違い：画面表示は事前にサーバーでHTMLを組み立てて提供すればいい(サーバーコンポーネント)が、イベントハンドラーはイベント発生時にサーバー処理を動かす必要がある(ので、普通に考えるとクライアント側にロジックをもたせる必要があるが、それだとセキュリティ上危険)。 ■3. 'use server'の役割：イベント発生時に動かすDB操作等のロジックをクライアント側に持たせるとまずいため、先頭に'use server'と書くことで、Next.jsが単なる関数呼び出しを暗黙のAPI通信に自動変換し、ロジックをクライアントから見えないように隠蔽して安全に処理を実行してくれる。
- **2026-08-06 16:48**: 画面と処理の分離（actions.ts/page.tsx）：画面をどう表示するかをpage.tsxに書き、入力やクリック時にイベントハンドラーから呼び出す処理をactions.tsからインポートして実行する。
- **2026-08-05 16:04**: DBを操作する関数の置き場所（db/users.ts）：テーブルごとに db/テーブル名.ts というファイルを作り、そのテーブルを操作する関数（CRUD処理）を1つのファイルにまとめて置いておくのが現代の開発の定番パターン。
- **2026-08-05 08:24**: DBへのINSERTという目的は果たしたのに、あえてnewUserをreturnする理由: 登録後に画面をリロードせず、「◯◯さんの登録が完了しました」と名前を表示したり、マイページへ自動遷移（リダイレクト）させたりして、スマホアプリのような爆速で心地よい操作感（UX）を作るため。

## 💬 Interview FAQ

### Q: 就職したらどのように貢献できるか？
A: セキュリティスペシャリスト(SC)の知識を活かし、JSTQBの標準的なテスト技法に基づいて、Playwrightを活用したテスト自動化を構築できます。

### Q: なぜ37歳実務未経験でITエンジニアを目指すに至ったのか？
A: 現職の業務効率化のためにExcelマクロを使うようになり、プログラミングが楽しいと感じて仕事にしたいと考えたのが始まりです。当初は、「いつか個人開発や案件で生計を立てられたらいいな」という程度の考えで、転職時期については深く考えずに、趣味レベルで独学を続けていました。しかし、子どもが生まれたことをきっかけに、育休終了後の生活について夫婦で話し合った結果、「リモートワークができる企業への転職」が最適であるという結論に至りました。そこで、自分に合いそうな職種として、セキュリティに強いQAエンジニアというポジションを目指すことにしました。

### Q: 具体的にどのような勤務形態を想定しているか？
A: フルフレックスの原則リモートワークを想定していますが、採用後最初の3ヶ月間を上限として、職場のルールや基本業務をキャッチアップするための期間であれば、出社可能です。それ以降は、子どもの幼稚園の送り迎えのため、原則リモートワークの勤務形態へ移行する必要があります。なお、リモート移行後も、月1回程度の頻度や、事前に調整ができるスケジュールであれば、家族と調整のうえ出社可能です。リモート移行後の普段の働き方としては、例えば、次のような形であれば可能です。

* **5:00 ~ 7:00 2時間勤務**
  (8:30前後に幼稚園送迎)
* **9:00 ~ 13:00 4時間勤務**
  (14:00前後に幼稚園送迎)
* **20:00 ~ 22:00 2時間勤務**
* **合計: 8時間勤務**

なお、14時から20時頃は子どもが家にいるため、業務に専念する時間（勤務時間）にはカウントできないものと考えております。ただし、その時間帯もスマートフォン等での急ぎのご連絡には随時対応可能ですので、チームの業務進行に支障が出ないよう配慮します。子育ての都合で毎日決まって同じ時間に働くことは難しいかもしれませんが、状況に応じて妻や実家のサポートを受けながら、月の総労働時間をしっかりと確保いたします。
